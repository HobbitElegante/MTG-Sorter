MTG Commander Collection Manager - Project Handoff

Objetivo
========
Desarrollar una aplicación de escritorio para administrar una colección física de Magic: The Gathering enfocada en Commander.

La aplicación debe permitir:

- Mantener un inventario físico de cartas.
- Guardar listas de mazos.
- Saber qué mazos están armados y cuáles desarmados.
- Saber exactamente qué cartas están ocupadas por cada mazo.
- Calcular automáticamente la mejor forma de rearmar un mazo desarmando el menor número posible de mazos existentes.

La idea central NO es hacer un deckbuilder, sino un optimizador de colección.

Objetivo principal
==================
Resolver automáticamente qué mazos deben desarmarse para armar otro utilizando la menor cantidad posible de desmontajes.

Modelamiento matemático
=======================
Sea:
- D = conjunto de mazos armados.
- C = conjunto de cartas requeridas.
- I = inventario libre.

Cada carta requerida puede provenir del inventario libre o de uno o más mazos armados.

El problema consiste en encontrar el conjunto mínimo de mazos cuya unión libera todas las cartas necesarias.

Esto corresponde a un problema de Set Cover.

Implementación propuesta
========================
Fase 1
-------
Algoritmo Greedy.

Mientras existan cartas faltantes:
1. Calcular qué mazo libera la mayor cantidad de cartas pendientes.
2. Seleccionarlo.
3. Eliminar esas cartas del conjunto pendiente.
4. Repetir.

Fase 2
-------
Implementar una solución exacta mediante Programación Lineal Entera.

Evaluar:
- OR-Tools
- PuLP
- scipy.optimize

Comparar la calidad de la solución respecto del algoritmo Greedy.
